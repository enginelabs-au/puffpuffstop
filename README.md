# PuffPuffStop

Break the cycle, reclaim your lungs.

PuffPuffStop is a **16+** iOS/Android wellness habit coach for teens and young adults who want to cut down and stop vaping. It is cute and teen-friendly. It is **not** a kids app, **not** a medical device, and **not** a payments product.

This repository is the local working copy of [enginelabs-au/puffpuffstop](https://github.com/enginelabs-au/puffpuffstop).

## Phase 0

Local foundations only: Expo + TypeScript + Expo Router skeleton, design tokens, age-gate stub, empty brand catalog, lint/test/typecheck, and a Supabase folder with an empty migration baseline. No store submit. No remote database mutation.

```bash
npm install
npm run lint
npm test
npm run typecheck
npm start
```

Environment-variable **names** (never commit values) live in `.env.example`.
